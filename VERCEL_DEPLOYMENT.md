## 2. Exactly What to Paste into Vercel

When importing your project into Vercel, copy and paste the following values under the **Environment Variables** section:

* For **Key**, enter `DATABASE_URL`
  For **Value**, paste:
  ```text
  postgresql://neondb_owner:npg_mJUozFQ3ks8c@ep-blue-tooth-aodyvsnu-pooler.c-2.ap-southeast-1.aws.neon.tech/neondb?sslmode=require
  ```

  For **Value**, paste a secure secret key, e.g.:
  ```text
  aura-luxe-secret-key-102938
  ```

## 4. Commands to Run After Pulling Code

If you or another developer pulls the latest repository code on a clean local machine, run the following commands in sequence to setup:

```bash
# 1. Install dependencies
npm install

# 2. Generate the local Prisma Client binary
npx prisma generate

# 3. Synchronize database tables & relationships (Run this only once or on schema update)
npx prisma db push

# 4. Populate database tables with mock products, admin accounts, and settings
node prisma/seed.js

# 5. Build application for production
npm run build

# 6. Start the production server locally (e.g. on port 3001)
npx next start -p 3001
```

## 5. Vercel Build Settings

You can keep the **Build Settings** on Vercel at their **default values**. 
* **Build Command**: `npm run build` (or `next build`).
* **Install Command**: `npm install`.
* **Output Directory**: `.next`.

We configured a `"postinstall": "prisma generate"` script in your `package.json` file. This automatically runs during the installation phase on Vercel, so the default build command (`npm run build` or `next build`) works out of the box.

## 11. Verification Steps After Deployment

Once the Vercel build completes and provides a live preview URL, open your browser and verify:

1. **Homepage & Catalog**: Go to the homepage and verify products like the *Eclipse X1* show up. Navigate to `/speakers` and `/turntables` to ensure the lists load correctly.
2. **Product Detail Rendering**: Click on *Eclipse X1* and verify its details and technical specs (which parse from dynamic JSON) show up without error.
3. **Authentication (Sign Up & Login)**:
   * Go to `/login`. Click **Create Account** and register a test user. Verify it log you in.
   * Log out, then log in using the seed admin user (`admin@aurashowroom.com` with password `admin123`).
4. **Admin Dashboard**: Go to `/admin` using your admin account. Verify that the Orders, Products, and Showroom Bookings lists load.
5. **Checkout & Order Creation**: Add a product to your cart, navigate to `/checkout`, enter delivery details, and click **Place Order**. Verify the order is created and redirects you.
6. **Inquiry / Book Demo**: Go to `/book-demo`, fill out the demo scheduling form, and submit. Log in as admin and verify the inquiry shows up under the bookings list.
